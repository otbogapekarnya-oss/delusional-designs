# Delusional Designs® — first build

A responsive, one-page Next.js starter for the first visual direction: typographic minimalism with a few art-directed details.

## Run locally

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## First-pass notes

- Responsive layout for desktop, tablet and mobile.
- Editorial typography and a restrained paper/ink palette.
- No fake case studies, client logos, testimonials, or invented metrics.
- The email address and all copy are placeholders to review before launch.
- Google Fonts are loaded remotely; for a production build, consider self-hosting the fonts.
